Schema cheat-sheet

Root must be an array of current-schema sessions. Extra fields are kept. Empty [] is valid and wipes history.

[{
  "id": "sess_1710000000000",
  "date": "2026-08-14",
  "startTime": 1710000000000,
  "endTime": 1710003600000,
  "players": ["Alice", "Bob"],
  "schedule": [{
    "matchNum": 1,
    "player1": "Alice",
    "player2": "Bob",
    "breaker": "Alice",
    "winner": null,
    "duration": 0,
    "completed": false
  }],
  "playedGames": [{
    "matchNum": 1,
    "player1": "Alice",
    "player2": "Bob",
    "breaker": "Alice",
    "winner": "Alice",
    "duration": 180,
    "round": 1
  }],
  "games": [{
    "matchNum": 1,
    "player1": "Alice",
    "player2": "Bob",
    "breaker": "Alice",
    "winner": "Alice",
    "duration": 180,
    "round": 1
  }],
  "currentMatchIndex": 1,
  "completed": true,
  "totalDuration": 180
}]
  • players: 2–8 unique names
  • schedule: one slot per unique pair (n×(n−1)/2)
  • games must match playedGames
  • Legacy player1/player2 sessions are rejected
  • Times are milliseconds; durations are seconds
